Put test models here (they are not bundled). For example the DamagedHelmet
(CC-BY 4.0, theblueturtle_) from the Khronos glTF sample assets:

    curl -L -o assets/DamagedHelmet.glb \
      https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/DamagedHelmet/glTF-Binary/DamagedHelmet.glb

The hair grooms used by the README and `examples/groom.rs` (`straight.hair`,
`wCurly.hair`) come from https://www.cemyuksel.com/research/hairmodels (free for
personal and research use; link to that page if you publish anything made from
them). Download them with `scripts/fetch_grooms.sh` or, on Windows,
`scripts\fetch_grooms.ps1`.
